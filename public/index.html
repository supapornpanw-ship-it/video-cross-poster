1) เชื่อมต่อบัญชี

Facebook
ยังไม่ได้เชื่อมต่อ
ขอที่ Graph API Explorer → App 721475520495705 → permissions: pages_show_list, pages_manage_posts, pages_read_engagement
ใช้กรณีเพจอยู่ใน Business Manager → ขอ Page Access Token โดยตรงจาก Business Settings → System Users หรือ Graph API Explorer (เลือก Page Token แทน User Token)
YouTube
ยังไม่ได้เชื่อมต่อ
YouTube ฟรีโควต้า = 10,000 units/วัน/แอป = ~6 อัปโหลด/วัน รวมทุกคนที่ใช้แอปนี้
ถ้าอยากมีโควต้าของตัวเอง สร้าง Cloud Project ของตัวเอง แล้วใส่ Client ID + Secret ที่นี่

วิธีตั้ง:
1. ไป Google Cloud Console → สร้าง Project ใหม่
2. APIs & Services → Library → เปิดใช้งาน YouTube Data API v3
3. APIs & Services → OAuth consent screen → External + Testing mode → ใส่ email ตัวเองใน Test users
4. APIs & Services → Credentials → Create Credentials → OAuth client ID → Web application
5. Authorized redirect URIs ใส่: ...
6. กด Create → คัดลอก Client ID + Client Secret มาวางด้านล่าง
